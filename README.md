
Django Product Management System

A simple Django application to manage products with CRUD operations and image upload functionality.

Technologies Used
- Python 3.12
- Django 5.x
- SQLite3
- Pillow (for image upload)
- HTML, CSS, Bootstrap

How to Install
1. Clone the repository
git clone https://github.com/snehabenny12/Project.git
cd Project

2. Create virtual environment
python -m venv .venv
.venv\Scripts\activate

3. Install dependencies
pip install -r http://requirements.txt

How to Run
1. Apply migrations
python http://manage.py migrate

2. Run the server
python http://manage.py runserver 8010

3. Open in browser
http://127.0.0.1:8010/
